A Java Developer's Journey into the Python Jungle!

Welcome to Python Arachakam!

I'm a Java developer who decided to explore Python. Coming from the world of Java, where curly braces rule everything, entering Python feels like moving into a completely different universe.

No semicolons, no curly braces, indentation everywhere, and somehow is, ==, and := all have different stories to tell. 😂

This repository documents my Python learning journey through hands-on coding, small challenges, experiments, mistakes, and occasional moments of confusion.

The goal: Learn Python properly, understand its philosophy, and become comfortable writing Pythonic code.
